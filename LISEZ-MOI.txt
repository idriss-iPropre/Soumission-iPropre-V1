RETOUR AUX LIENS IS.GD - 20 mai 2026
=====================================

Problème :
  Les nouveaux liens courts générés via le backend Google Sheets
  (format ?mode=client&s=GMpcB&...) ne fonctionnaient plus — la page
  restait blanche car la résolution côté serveur échouait.

Solution :
  Retour à l'ancien système éprouvé : on construit l'URL complète avec
  les données encodées DANS l'URL (?mode=client&data=...) puis on la
  raccourcit via is.gd / v.gd / tinyurl. Ces services se contentent
  d'une redirection HTTP — pas de dépendance backend.

Avantages :
  - Les liens ouvrent instantanément (juste une redirection)
  - Pas de dépendance Apps Script / Google Sheets
  - Les liens restent valides à vie tant que le service de
    raccourcissement existe
  - Compatible avec vos anciens liens (https://is.gd/KqB0QZ etc.)

Fichier à déployer :
  - envoi.jsx (remplacer le fichier existant)

Note : les liens déjà générés avec ?mode=client&s=... ne fonctionneront
toujours pas — il faut les régénérer. Les NOUVEAUX liens seront du
format raccourci is.gd (ex : https://is.gd/AbCdEf) qui marchent comme
au premier jour.
