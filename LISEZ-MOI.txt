IS.GD PRIORITAIRE - 20 mai 2026
================================

Problème :
  Les liens passaient par TinyURL → tinyurl.com/preview/deprecated/xxx
  → page d'attente de 5 secondes avec pubs avant la redirection.

Cause :
  L'ancien code tombait sur TinyURL dès que l'URL dépassait
  4800 caractères. Or :
    - La vraie limite is.gd est ~5000 caractères (pas 4800)
    - TinyURL impose maintenant une page de prévisualisation
      avec publicités sur tous les liens api-create.php

Solution :
  is.gd est maintenant essayé EN PREMIER, peu importe la longueur.
  Il refusera lui-même si trop long, et on passe à v.gd. TinyURL
  n'est utilisé qu'en TOUT DERNIER RECOURS.

Résultat attendu :
  Nouveaux liens : https://is.gd/abc123  (redirection directe,
                                          comme vos anciens liens)
  Fallback v.gd : https://v.gd/abc123    (redirection directe)
  Dernier recours TinyURL : seulement si URL > 5000 caractères

Fichier à déployer :
  - envoi.jsx (remplacer)

Si vous voyez ENCORE un lien tinyurl.com après déploiement :
  - Soit votre URL > 5000 caractères (la soumission a beaucoup
    de lignes/contenu) — dans ce cas, raccourcir un peu les
    libellés ou supprimer des lignes vides
  - Soit GitHub Pages n'a pas encore republié (Cmd+Shift+R)

Vérification dans la console :
  [iPropre] createShortLink v2 (is.gd/tinyurl) — long URL length: ...
  Si length < 5000 → vous DEVEZ avoir is.gd/...
  Si length ≥ 5000 → la soumission est trop volumineuse
